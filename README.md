## Features
- [x] Search by GitHub username
- [x] Detailed profile view (avatar, bio, stats, repos)
- [x] Loading and empty states
- [x] Data fetching from the GitHub API
- [x] Link to the user's profile
- [x] Light/Dark mode
- [x] Random user
- [x] Site information
<br/>

## Rate limit
Because of the GitHub API's rate limit, you can make up to 60 requests per hour.
